# Swadishtha - Django E-commerce Project

## Project Overview
Swadishtha is a full-stack e-commerce web application built with Django, designed to provide a seamless online shopping experience. The platform will handle product catalog management, user authentication, shopping cart functionality, order processing, and payment integration.

## Core Business Idea
An online marketplace that connects local food artisans and home chefs with customers looking for authentic, homemade culinary products. The platform specializes in traditional recipes, organic food items, and artisanal food products that aren't typically available in regular supermarkets.

## Tech Stack

### Backend
- **Framework**: Django 6.0.2
- **Database**: PostgreSQL
- **Authentication**: Django's built-in auth
- **Payment Gateway**: Razorpay

### Frontend
- **Templates**: Django Templates with tailwindcss
- **CSS Framework**: tailwindcss for responsive design
- **JavaScript**: Vanilla JS with AJAX for dynamic features
- **Form Handling**: Django Crispy Forms

### DevOps & Tools
- **Version Control**: Git + GitHub
- **Environment Management**: python-decouple for env variables
- **Package Management**: pip + requirements.txt
